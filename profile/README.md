## What is Galaxis Forge?

Galaxis Forge is a place for **building and exploring software ideas**.

We take ideas through the whole product journey — understanding the problem, designing the experience, building the system, and shipping something real.

That might mean a complete product.

It might mean an open-source tool, a protocol, a weekend experiment, or a prototype built simply to answer **“what if?”**

Not everything here needs to become a company.

**It just needs to be worth building.**

## How we build

We don't define ourselves by a particular framework or language.

We choose the tools that make sense for the product.

| Layer | Tools |
|---|---|
| **Interface** | TypeScript · React · Next.js |
| **Desktop** | Tauri · Rust |
| **Backend** | Node.js · Rust |
| **Data** | PostgreSQL · Redis |
| **Infrastructure** | Docker |
| **Protocols** | Solidity · EVM · Solana |

These are tools we use today.

Tomorrow's stack might look different.

> **Choose technology for the problem — not the other way around.**

## Principles

### Build the smallest useful thing

Don't spend months answering a question that a prototype could answer in a weekend.

Start small. Put it in front of reality. Learn what matters.

### Keep complexity on a leash

Good software isn't impressive because it has more architecture.

It's impressive when the architecture disappears and the product simply works.

### Think in products, not layers

Frontend, backend, infrastructure, and design aren't separate experiences for the person using the product.

We care about the whole path:

**idea → interaction → system → outcome**

### Learn by building

New technologies are interesting.

Using them to build something is more interesting.

Experiments don't need to succeed to be valuable — sometimes understanding why something doesn't work is the result.

### Ship

Eventually, software has to leave localhost.

> **Stop polishing the hammer. Start forging.**

**One repository at a time.**
